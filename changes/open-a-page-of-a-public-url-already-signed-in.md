## Open any page of a public URL already signed in

A link with the password now signs a browser in with no click, even the first time it
opens the URL, and `localify public-url link https://admin.journal.localify/orders/42`
gives the link to one exact page. Coding agents get the same through `public_url_link`,
so an agent can put you on the page it means from your phone. The password, warning and
error pages of public URLs also look like Localify now, in light and dark.
