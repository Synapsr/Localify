# Native Public Endpoint Connector

Public endpoints use a native Localify connector integrated with the Localify runtime instead of launching an external tunnel binary. This keeps endpoint availability, selected machine ownership, logs, lifecycle controls, and local-domain routing inside the same Rust-first product boundary that the desktop app already drives through `DesktopApi`. Enabled public endpoints reconnect automatically when the daemon starts; disabling an endpoint keeps its reservation while making it intentionally offline. Connector availability is distinct from local target reachability, DNS verification, and certificate readiness so Localify can diagnose public endpoint failures without collapsing them into a single "down" state. Endpoint creation is allowed even when the local target is not currently reachable; the public URL can be provisioned while Localify reports the target as unavailable until the dev server starts. Connectors authenticate with short-lived tokens scoped to the endpoint, machine, and license identity, rather than sending the license key over every long-lived connector session. Only the selected machine may actively serve an endpoint; switching machines is an explicit claim that replaces the previous connector session, and automatic daemon reconnects must not silently take over endpoints served by another machine. Endpoint runtime status and public URL provisioning status are modeled separately; UI presentation can be refined later without merging those concepts.

## Considered Options

In September 2026, Localify reconsidered running `cloudflared` against Cloudflare Tunnels that Localify Cloud would create per machine through the Cloudflare API. It would have avoided writing a multiplexing protocol, since `cloudflared` already handles streaming, SSE, WebSockets, and reconnection. The native connector stays for four reasons. Cloudflare accounts are limited to 1,000 tunnels by default. Workers VPC bindings are declared in the Worker configuration, so the edge Worker could only reach per-machine tunnels through public origin hostnames, which bypass access protection unless secured separately. Localify would have to download and supervise a large external binary. Reselling tunnel capacity would need Cloudflare's agreement. [traforo](https://github.com/remorses/traforo) (MIT) runs the same Durable Object and WebSocket design with HTTP streaming, SSE, and WebSocket passthrough, and is a reference for the wire protocol.
