# Public URLs Run on Named Cloudflare Tunnels

Public traffic reaches a machine through one named Cloudflare Tunnel per signed-in machine, run by `cloudflared`, instead of a Localify connector multiplexing requests over a WebSocket to a Durable Object. This supersedes ADR 0003 and the data-plane part of ADR 0005. Localify Cloud creates each tunnel through the Cloudflare API with the configuration held by Cloudflare, so the user never touches a Cloudflare account; the daemon downloads a pinned, checksummed `cloudflared` on first use, gives it the tunnel token through its environment, and supervises it like any other child process.

The native connector was built as a spike and measured on a real network on 2026-11-05, with the dev server on one Mac and the browser on a laptop on another ISP. It worked, but a review by Codex argued that a production version would need flow control, generation-qualified stream ids, machine claims, protocol validation and a cap on upstream connections, all of it transport code for one maintainer, while the reasons ADR 0003 gave against `cloudflared` had aged: the 1,000-tunnel allowance can be extended, and Cloudflare documents tunnels for platforms that serve their own customers. Measured on the same networks, a Worker that checks the access cookie and forwards to a named tunnel answered in 59 to 64 ms per request against 84 to 104 ms for the Durable Object design, and loaded a 336-module Vite page in 1.0 s against 2.15 s, with HMR, SSE, large transfers and request bursts all passing.

The public Worker stays in front: it owns the password, the URL lookup and the mapping from public to local host. The tunnel's hostname is public, so the Worker sends a per-machine ingress secret and the daemon refuses any request without it. Cloudflare rewrites `X-Forwarded-Host` before the request reaches the tunnel, so the public host travels in `X-Localify-Public-Host`, trusted only together with that secret. Selling access to Cloudflare tunnels as part of a paid offer needs Cloudflare's written confirmation first.
