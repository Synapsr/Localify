# Public Endpoints Are CLI Accessible

Every public endpoint operation available in the desktop UI must also be available through the Localify CLI so agents and scripted workflows can perform the same work without manual UI steps. The Rust application layer owns the public endpoint use cases, and both DesktopApi and CLI commands delegate to those use cases rather than implementing separate behavior. The user-facing CLI namespace is `localify public-url`, even though the internal domain model uses public endpoints with one or more public URLs. Public URL commands render human-readable output for interactive terminals, automatically render JSON when stdout is not a TTY, and support `--json` to force machine-readable output. Interactive prompts are allowed in TTY sessions, but every prompt must have a flag-driven non-interactive path; non-TTY execution must never block waiting for input.
