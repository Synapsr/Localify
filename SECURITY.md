# Security Policy

Localify installs a local certificate authority, runs a privileged system
helper, and manages local DNS. Security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/Synapsr/Localify/security/advisories/new).

Include as much of the following as you can:

- affected version and operating system
- a description of the issue and its impact
- steps to reproduce or a proof of concept

You should receive an acknowledgement within a few days. Please give us a
reasonable amount of time to ship a fix before disclosing the issue publicly.

## Supported versions

Only the latest released version receives security fixes.
